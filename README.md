## 🚀 Projects

### 🤖 NOVA AI – Personal AI Assistant

NOVA AI is a personal AI assistant designed to provide intelligent interactions, assist with tasks, and run AI models locally. The project focuses on integrating local language models with a backend system to create a responsive and extensible AI assistant.

- **Features:**
  - AI-powered conversational interaction.
  - Local LLM integration using Ollama.
  - Qwen2.5 7B model support.
  - Backend API built with FastAPI.
  - Chat history management using SQLite.
  - Streaming AI responses using Server-Sent Events (SSE).
  - Local tool integration.
  - Optional web search capabilities.

- **Technologies:** Python, FastAPI, Ollama, Qwen2.5 7B, SQLite, SSE.
- **Status:** Under development.
